# Live evidence, framed for a judge

Use a fixed dark terminal and a quiet side rail to make real tool calls and their
consequences readable. Terminal text is the focal element; the side rail anchors
the workflow; the bottom line states provenance and demo-only auto-approval.

Palette: background #141b18, surface #1e2923, foreground #eff5ef, muted #b4c6b8,
accent #b7e08a. Flat surfaces, no decorative effects.

Typography: bundled IBM Plex Mono 400/700 for the terminal; bundled Outfit 400/700
for headings and supporting labels. Terminal 23px is intentionally smaller than
display type because source output contains tables and path identifiers.

Motion: discrete seek-safe updates to actual terminal output; a linear progress
bar; phase highlights from recorded audit timestamps. No simulated tool calls.
